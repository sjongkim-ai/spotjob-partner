# 스팟잡 파트너

PC방 사장님과 알바(스팟 파트너)를 잇는 채용 앱 시안입니다. 설치 없이 브라우저에서 도는 정적 PWA이고, 규칙(법령·매칭·상태 전이)은 나중에 백엔드로 그대로 옮길 수 있게 분리해 두었습니다.

기준 문서: [CLAUDE-PCBANG.md](CLAUDE-PCBANG.md)

## 실행

```bash
node pcbang-app/serve.js
```

그다음 크롬에서 <http://localhost:5173/> 을 엽니다.

> `index.html` 파일을 그냥 더블클릭해서 열면 서비스워커·앱 설치·오프라인이 동작하지 않습니다. 반드시 위 서버로 여세요.

같은 와이파이에 연결된 휴대폰에서는 서버가 알려주는 `http://<내 PC 주소>:5173/` 로 접속해 볼 수 있습니다.

## 화면

| 주소 | 앱 |
|---|---|
| `/` | 시작 화면 (파트너 / 사장님 선택) |
| `/#jobseeker` | 스팟 파트너 앱 — 내 정보, 공고 찾기, 지원·서류 |
| `/#pcbang` | 사장님 앱 — 매장·공고, 지원자·채용 |
| `/#admin` | 어드민 — 매장 승인, 서류 확인, 컴플라이언스, 배치, 매칭 가중치 |

각 앱은 화면 아래 고정된 바로가기 메뉴로 주제를 나눠 이동합니다.

| 앱 | 메뉴 |
|---|---|
| 파트너 | 내 정보 · 공고 찾기 · 내 지원 · 서류 · 도움방 |
| 사장님 | 매장 · 공고 · 지원자 · 채용 확인 · 도우미 |
| 어드민 | 매장 승인 · 서류 확인 · 안전 점검 · 배치 · 매칭 설정 |

화면마다 `data-panel`로 주제를 적어두고 메뉴가 그 주제만 보여줍니다. 카드를 새로 추가할 때는 `data-panel`만 붙이면 됩니다.

세 앱은 한 브라우저의 저장소를 함께 쓰기 때문에, 사장님이 올린 공고에 파트너가 지원하고 어드민이 서류를 확인하면 사장님이 채용을 확정하는 흐름이 이어집니다. 어드민 화면의 "데모 데이터 초기화"로 처음 상태로 되돌릴 수 있습니다.

## 테스트

```bash
node pcbang-app/tests/rules.test.js
```

법령 기준, 매칭, 상태 전이 규칙의 단위 테스트입니다.

## 폴더

```
pcbang-app/
  serve.js              로컬 개발 서버
  public/
    index.html          세 앱 화면
    service-worker.js   오프라인·캐시 (같은 출처는 네트워크 우선)
    js/
      legal.js          법령 수치와 판정 (최저임금·연소자 기준·사업자번호)
      schema.js         데이터 모델 enum과 표시 이름
      matching.js       하드 필터, 적합도 점수, 프로필 완성도
      workflow.js       공고·지원 상태 전이, 서류 검증, 배치, 감사 로그
      seed.js           데모 데이터
      store.js          브라우저 저장소 (나중에 API 호출로 교체)
      ui-*.js           파트너·사장님·어드민 화면
  tests/rules.test.js   규칙 단위 테스트
```

## 지금 상태에서 알아둘 점

- **백엔드가 없습니다.** 모든 검증이 브라우저 안에서만 돌고, 데이터는 그 브라우저에만 저장됩니다. 다른 기기에서는 서로의 공고나 지원이 보이지 않습니다.
- PASS 본인인증, 국세청 사업자 진위확인, 서류 암호화 저장소는 연결 지점만 표시해 두었습니다.
- 연소자 서류는 원본과 파일명을 저장하지 않고 형식·크기만 기록합니다.
- 만 18세 미만 근무시간 한도는 1일 7시간 · 주 35시간입니다. 연장 합의(8시간·40시간) 인정 여부는 전문가 확인 전까지 기능 플래그로 꺼 두었습니다(명세 §13-5).
